## ✨ Overview

NIRVANAX is the **personalization** release: the assistant that becomes *yours*. Pick the voice it speaks with, tune the colour of the whole HUD, and watch it power on with a boot chime and a swelling animation like a machine coming to life. The interface now breathes with you too — the waveform and the arc-reactor core pulse to your **real** voice while you speak and to the assistant's own voice while it answers.

All of that sits on the Mark LI foundation: a plugin engine you extend without ever touching the core, native audio that hears the emotion in your voice, knows when you're not talking to it, and can hold one conversation for hours.

It's not just an assistant — it's an extension of your digital life.

## 🚀 Capabilities & Core Features

- 🎙️ **Voice Picker:** Choose from 5 native Gemini voices and switch live from the UI — no restart.
- 🎨 **Live Theming:** Recolour the entire HUD from a hue wheel or hex — applied instantly across every panel.
- 〰️ **Reactive HUD:** Waveform and reactor core pulse to real audio — your mic while listening, JARVIS while speaking.
- 🧠 **Recallable Memory:** No size limit and nothing silently forgotten.
- 👁️ **Memory Panel:** See every fact JARVIS has stored about you, and delete any of it in one click.
- ↩️ **Undo Actions:** Take back what the assistant did — files it moved, renamed, created, or settings it changed.
- ⚠️ **Real Confirmation:** Shutdown, restart, and WiFi wait for a button **you** press.
- 🎧 **Audio Device Picker:** Choose the microphone and speakers by name.
- 🔗 **Session Continuity:** A dropped connection no longer wipes the conversation.
- 🧩 **Plugin System:** Drop a single `.py` file into `plugins/` — JARVIS learns a new skill on next launch.
- 🎙️ **Real-time Voice & Affective Dialog:** Hears the emotion in your voice and adapts its tone in response via Gemini Live.
- 🤫 **Proactive Audio:** Knows when you're not talking to it. Background chatter never triggers a reply.
- 🖥️ **System & Desktop Control:** Launch apps, adjust volume/brightness, WiFi, shortcuts, power, and more — all by voice.
- 👁️ **Visual Awareness:** Real-time screen capture and webcam vision piped into your main session.

## ⚡ Quick Start

```bash
git clone https://github.com/SayantanTheCmd/NirvanaX.git
cd NirvanaX
pip install -r requirements.txt
python main.py
```

> ⚠️ **Installation Note:** Some OS-specific dependencies are not bundled in `requirements.txt` to keep the repo lightweight. If you hit a `ModuleNotFoundError`, install the missing package with `pip install <module_name>`.
